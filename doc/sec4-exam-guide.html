4.0 Domain 4 roadmap: Evaluating and deploying workflows (22% weight)

Domain 4 in a nutshell (~22% exam weight)
  • Trajectory and rubric evaluation (4.1): Grade tool sequences with tool_trajectory_avg_score (EXACT, IN_ORDER, ANY_ORDER), grade open-ended quality with RubricBasedCriterion, and compare models via PointwiseMetric and PairwiseMetric in EvalTask.
  • Production runtimes and CI/CD rollouts (4.2 & 4.3): Choose between turnkey Managed Agent Runtime (AdkApp), serverless Cloud Run (with external SessionService), and GKE with Agent Sandbox (gVisor/microVMs); scaffold repos with Agent Starter Pack and enforce session-pinned canary and mocked shadow rollouts.
  • Observability and FinOps optimization (4.4): Pinpoint latency in Cloud Trace (OpenTelemetry spans + W3C traceparent), stream logs to BigQuery for offline autorater sampling, and reserve capacity via Provisioned Throughput.

Core architectural topics in Domain 4 (~22%)

1. Trajectory evaluation vs. final response and rubric evaluation (Module 4.1)
  • Build golden *.evalset.json datasets to test tool-call sequences (EXACT, IN_ORDER, and ANY_ORDER trajectory match modes) via AgentEvaluator.evaluate().
  • Configure ADK RubricBasedCriterion (rubric_based_final_response_quality_v1, rubric_based_tool_use_quality_v1) and Platform SDK autoraters (PointwiseMetric, RubricBasedMetric, PairwiseMetric).
2. Production runtime selection: Agent Runtime vs. Cloud Run vs. GKE (Module 4.2)
  • Select the optimal hosting platform based on managed session/memory integration (Agent Runtime), custom containers with serverless scale-to-zero (Cloud Run + external SessionService), or kernel-isolated code execution and custom GPU/TPU pools (GKE with Agent Sandbox).
3. Agent Starter Pack, CI/CD evaluation gates, and safe rollouts (Module 4.3)
  • Bootstrap multi-environment Terraform IaC, RAG ingestion pipelines, automated CI/CD evaluation gates, and telemetry sinks using the Google Cloud Agent Starter Pack.
  • Execute safe stateful rollouts using session-pinned canary routing (pinned by session_id), Blue/Green cutovers, and shadow (dark launch) testing with mocked mutating tools.
4. OpenTelemetry tracing, monitoring, and cost/latency optimization (Module 4.4)
  • Inspect multi-agent execution spans in Cloud Trace (propagating W3C traceparent headers across A2A/MCP), export logs to BigQuery for asynchronous autorater sampling and golden dataset harvesting, and tune production resilience with Provisioned Throughput and exponential backoff with jitter.
