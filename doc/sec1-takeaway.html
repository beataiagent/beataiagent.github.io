2. The 4-pillar Section 1 summary grid

1.1 Tiers and CoT
Automation vs. 1 vs. multi
  • Workflows/Dataflow: Fixed schemas.
  • Workflow Builder: No-code app tasks.
  • Single agent (+ CoT): 1 domain, <10 tools.
  • Multi-agent: 15+ tools, personas, parallel, or PAB.
1.2 Studio and bridge
Agent Designer and ADK
  • Agent Designer: Internal workforce + Agent Search ACLs + OAuth connectors.
  • Bridge to ADK: Reuse data_store_id or delegate behind the scenes via A2A.
1.2b Multimodal
Tables, charts, and video
  • Layout parser: Keeps PDF tables and headers intact.
  • Multimodal embeddings: Grounds on visual charts, images, and audio/video timestamps.
1.3 CX Agent Studio
Pages and composite voice
  • Hierarchy: Playbook ↔ Flow → Page (Slots + Transition Routes + Event Handlers).
  • Voice: Listener + Thinking + Speaker (Speaking style & <pause>), DTMF, and warm handoff.

Golden rules for Section 1

  1. Right-size agency: Use Cloud Workflows / Dataflow for fixed schemas, Workflow Builder for no-code multi-app tasks, a single agent (+ CoT) for 1 domain with under 10 tools, and multi-agent only for 15+ tools, conflicting personas, parallel fan-out, or IAM/PAB isolation.
  2. Studio vs. code: Use Agent Designer for internal employee search/actions, enable layout-aware multimodal ingestion for tables/charts/videos, and reuse your data_store_id when bridging to ADK.
  3. Omnichannel contact center: In CX Agent Studio (CES), combine Generative Playbooks (steered by Exemplars) with Deterministic Flow Pages (Transition Routes + Event Handlers), 3-part composite voice, and warm live-agent handoffs!
