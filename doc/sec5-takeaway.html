2. The 4-pillar security and governance summary

5.1 Perimeter defense
Gateway and Model Armor
  • Single SDP match: Redact inline + OAuth lookup.
  • Multi-detector match: Hard block.
  • 5 gateway engines: IAP UAP (roles/iap.egressor), semantic, token caps, custom authz, Model Armor.
  • Logs & traces: agentGatewayInfo.mcpInfo + telemetryPolicies.
5.2 Zero-trust identity
Identity, PAB, and OAuth 2.0
  • 1 agent = 1 SPIFFE identity: 24h X.509 rotation + mTLS/DPoP binding.
  • 3 outbound modes: GCP cert-bound, external OIDC/2-legged, or 3-legged user OAuth.
  • Policy order: 1. PAB (<=500) → 2. IAM Deny → 3. IAM Allow.
5.3 Runtime callbacks
ADK hooks and HITL
  • before_agent_callback: Returns types.Content (skips agent).
  • before_model_callback: Returns LlmResponse (skips LLM, $0 cost).
  • before_tool_callback: Returns dict (skips tool, triggers tool-level HITL).
5.4 Fleet governance
Registry, App Hub, and ADC
  • Agent Registry (≤5,000 res): With boundary (Folder/Org auto-discover) vs. without (Service + Binding).
  • ADC: Pre-deploy hardened templates.
  • App Hub: Owner, criticality, and outage topology.

4. Master “if you see X, pick Y” decision matrix (Section 5)

Architectural requirement or scenario Recommended Google Cloud solution Anti-pattern to avoid
Mask a single credit card number in a prompt while allowing the refund lookup to proceed Model Armor with Advanced SDP (de-identify template + INSPECT_AND_BLOCK) + out-of-band OAuth 2.0 session identity (or SDP surrogate token). Blocking innocent single-PII prompts or passing raw PAN digits to the LLM.
Enforce default-deny authorization per MCP tool name or cap shared token budgets at the gateway Agent Gateway with IAP Unified Access Policies (roles/iap.egressor), semantic governance, and token management policies. Relying on unauthenticated MCP endpoints or per-agent custom Python rate limiters.
Keep outbound Agent-to-Anywhere traffic inside a VPC Service Controls perimeter Agent-to-Anywhere (egress) gateway configured with a Private Service Connect (PSC) network attachment. Routing sensitive enterprise tool egress over unguarded public internet paths.
Audit which MCP method and tool name traversed the gateway or enable gateway distributed tracing Query agentGatewayInfo.mcpInfo in Cloud Logging and import telemetryPolicies via gcloud beta network-services telemetry-policies import. Guessing tool usage from application stdout logs alone.
Enforce a non-negotiable minimum safety threshold across all projects in an Organization Model Armor Floor Settings at the Organization or Folder node. Relying on individual project owners not to weaken local templates.
Prevent an agent from being tricked into modifying User B’s records on behalf of User A Agent Identity Auth Manager with 3-legged OAuth 2.0 user delegation (single-scope for GitHub/Microsoft; app-level for ServiceNow). Authenticating user-specific tool calls with the agent’s shared service account.
Prevent stolen agent access tokens from being replayed from an external machine Managed Agent Identity with 24-hour X.509 rotation and default Context-Aware Access (mTLS + DPoP token binding). Using static, long-lived service account JSON keys.
Ensure a Support Agent can never access R&D folders even if granted an IAM Allow role Principal Access Boundary (PAB) policy bound to the Support Agent’s identity (up to 500 resources). Relying solely on periodic manual IAM audits.
Skip calling Gemini and return a verbatim legal notice at zero token cost before_model_callback returning an LlmResponse object (or before_agent_callback returning types.Content). Returning a dict from before_model_callback or relying on system prompt instructions.
Pause a refund(amount=2500) call for supervisor approval before the API executes before_tool_callback returning a Python dict (tool-level HITL). Attempting to inspect JSON tool arguments inside a Cloud IAM policy condition.
Automatically discover agents across a GCP Folder vs. register external multi-cloud MCP servers Agent Registry WITH a Management Boundary (Folder/Org auto-discovery) vs. WITHOUT a Management Boundary (manual Service + Binding). Manually registering every internal GCP agent or leaving multi-cloud MCP servers ungoverned.
Standardize pre-deployment security blueprints vs. map outage ownership vs. catalog MCP tools ADC (Day 0 pre-deploy blueprints) + App Hub (Day 2 ownership/criticality) + Agent Registry (runtime A2A/MCP catalog). Mixing up pre-deployment (ADC) with runtime discovery (Agent Registry).
