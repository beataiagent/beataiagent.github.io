2. The 4-pillar Section 2 summary grid

2.1a Rules and skills
Smart context loading
  • 4 rule triggers: always_on, glob (file type), model_decision (topic), manual (@).
  • Skills: Upgrade old workflows via /migrate-workflows to SKILL.md.
2.1b Hooks and plugins
Automatic code gates
  • hooks.json: PreToolUse blocks bad commands; PostToolUse auto-formats edited files.
  • plugin.json: Bundles rules, skills, hooks, and MCP for your whole team.
2.2 agents-cli and subagents
ADK skills and clean memory
  • agents-cli: Adds 7 built-in skills to build, test, deploy, and tune ADK agents.
  • define_subagent: Explorer, Coder, and Verifier in separate memory windows.
2.3 GKE Sandbox and speed
Safe code and fast runtimes
  • Headless CLI: agy / gemini JSON mode in CI/CD.
  • GKE Agent Sandbox: gVisor / microVMs + warm pools.
  • Speed tuning: Cloud Trace → Flash + Caching.

3. Cross-tool master decision matrix (Antigravity agy, agents-cli, Gemini CLI, and Claude Code)

Architectural requirement or scenario Recommended architectural solution Anti-pattern to avoid
Share universal build, test, and architecture conventions across every developer on a repo Commit a concise repository root context file (GEMINI.md / CLAUDE.md / always_on rule) to Git. Storing mandatory team conventions in a developer’s personal global home-directory config.
Prevent backend Python rules from colliding with frontend React or Terraform rules in a monorepo Create modular rules in .agents/rules/*.md with trigger: glob (e.g., globs: ["**/*.tf"]) or place subdirectory-scoped context files in each package folder. Dumping all conflicting language rules into one giant always-on root context file.
Provide 25 specialized runbooks (migrations, security audits) without bloating every prompt Run /migrate-workflows and package each workflow as an on-demand custom skill (.agents/skills/<name>/SKILL.md, loaded via progressive disclosure). Pasting all 25 runbooks directly into the always-on root context file or leaving them in deprecated .agents/workflows/.
Guarantee a coding agent can never run git push --force OR auto-run a linter after every file edit Configure synchronous lifecycle hooks in .agents/hooks.json (or ~/.gemini/config/hooks.json / .gemini/hooks/) using PreToolUse and PostToolUse regex matchers. Writing a polite English note in GEMINI.md hoping the LLM remembers to run the formatter or avoid git push --force.
Prevent .env credentials, private keys, and node_modules from entering the AI context Configure deterministic context exclusion / ignore files (.geminiignore, .aiexclude, and PreToolUse deny hooks). Adding a natural-language sentence in the system prompt asking the AI not to read .env.
Share your team’s skills, rules, subagents, hooks.json, and MCP settings across 50 repos Package them inside a versioned plugin.json manifest. Manually copying and pasting .agents/ folders across 50 separate repositories.
Equip Antigravity (agy), Gemini CLI, or Claude Code to build, evaluate, and deploy ADK agents Augment the workspace with agents-cli (google.github.io/agents-cli) and its 7 built-in skills. Letting an unaugmented coding model guess outdated Vertex SDK classes or deployment flags.
Stop the coding assistant from hallucinating BigQuery/AlloyDB column names or internal APIs Connect the IDE/CLI to a read-only MCP server (such as MCP Toolbox for Databases or Cloud Logging MCP). Manually copying and pasting table schemas into chat on every turn or granting prod DB write access.
Refactor 50+ files across a repository without the agent forgetting instructions mid-task (context rot) Use subagent task decomposition (define_subagent) with Explorer, Coder (disjoint files), and Verifier subagents in isolated context windows. Forcing a single monolithic chat thread to search, edit, and test all 50 files sequentially.
Prevent an AI coding assistant from generating 20 files based on a flawed architectural assumption Follow a Spec → Plan → Act → Verify loop where a human architect reviews and approves the Plan before coding starts. One-shot prompting (“Build the entire microservice now”) without a specification or plan gate.
Run Antigravity (agy), Gemini CLI, or Claude Code inside Cloud Build / GitHub Actions without hanging Invoke the CLI in non-interactive headless mode with a pre-approved read-only tool allowlist and structured JSON output. Running default interactive mode (which blocks indefinitely waiting for terminal [y/N] input).
Rapidly create unit tests and golden *.evalset.json trajectory files for a new ADK agent Use AI-assisted test synthesis anchored on the written specification, followed by mandatory human verification. Blindly committing AI-generated assertions derived solely from buggy implementation code without review.
Execute untrusted AI-generated or user-submitted Python/C++/bash code safely with sub-second startup Deploy on Agent Sandbox on GKE using gVisor / Kata microVMs and pre-warmed sandbox pools with zero prod credentials. Running untrusted code in standard shared containers or enabling “auto-approve all commands” on a host machine with prod keys.
Speed up a slow, expensive deployed multi-agent runtime without losing accuracy Check Cloud Trace spans, tier simple steps to Gemini Flash, set include_contents='none', enable Context Caching, use async def / ParallelAgent, and verify with AgentEvaluator. Blindly shrinking max_output_tokens or shipping speed changes without running golden evaluation gates.

Golden rules for Section 2

  1. Smart context & deterministic gates: Use .agents/rules/*.md (always_on, glob, model_decision, manual) for coding rules, .agents/skills/<name>/SKILL.md (via /migrate-workflows) for on-demand recipes, hooks.json (PreToolUse / PostToolUse) for guaranteed code gates, and plugin.json to share across repos.
  2. ADK augmentation & clean memory: Install agents-cli (7 built-in skills), connect read-only MCP servers, and spawn custom subagents (define_subagent) inside a Spec → Plan → Act → Verify loop to prevent context rot.
  3. Safe execution & fast runtimes: Use non-interactive headless JSON mode in CI/CD, isolate untrusted code in Agent Sandbox on GKE (gVisor/microVMs + warm pools), and optimize runtimes via Cloud Trace + Gemini Flash + Context Caching + AgentEvaluator!
