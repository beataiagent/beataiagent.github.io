Domain 2 in a nutshell (~17% exam weight)
  • Rules, skills, plugins, and hooks (2.1): Configure Google Antigravity (.agents/rules/*.md with always_on, glob, model_decision, and manual triggers), upgrade legacy workflows to .agents/skills/<name>/SKILL.md via /migrate-workflows, bundle extensions in plugin.json, and enforce deterministic lifecycle hooks (hooks.json).
  • Augmenting with agents-cli, MCP, and subagents (2.2): Use agents-cli (7 built-in skills) and Antigravity CLI (agy) to build, evaluate, deploy, and govern ADK agents; prevent multi-file context rot with custom subagents (define_subagent / .agents/).
  • Headless CI/CD, GKE Agent Sandbox, and runtime optimization (2.3): Run agy / gemini in headless CI/CD mode, isolate untrusted code in Agent Sandbox on GKE (gVisor/microVMs), and execute systematic workflows to optimize agent runtimes.

Core architectural topics in Domain 2 (~17%)

1. Rules (.agents/rules), skills (SKILL.md), plugins, and lifecycle hooks (Module 2.1)
  • Configure Antigravity rules (.agents/rules/*.md) using YAML frontmatter triggers (always_on, glob, model_decision, manual) alongside hierarchical GEMINI.md and CLAUDE.md context files.
  • Migrate deprecated .agents/workflows/ to progressive-disclosure skills (.agents/skills/<name>/SKILL.md) using /migrate-workflows, and package shareable capabilities via plugin.json manifests.
  • Enforce synchronous lifecycle hooks (.agents/hooks.json, ~/.gemini/config/hooks.json, .gemini/hooks/) across PreToolUse / BeforeTool, PostToolUse, BeforeAgent, AfterModel, AfterAgent, and Stop with regex tool matchers.
2. Augmenting with Agents CLI (agents-cli), MCP, and custom subagents (Module 2.2)
  • Augment Google Antigravity (agy), Gemini CLI, and Claude Code with agents-cli (and its 7 built-in skills) to scaffold, evaluate, deploy, scale, and govern ADK agents on the Gemini Enterprise Agent Platform.
  • Author custom subagent definitions (define_subagent / .agents/) with isolated context windows to prevent multi-file context rot inside a Spec → Plan → Act → Verify loop, backed by live read-only MCP servers.
3. Headless CI/CD, Agent Sandbox on GKE, and runtime optimization (Module 2.3)
  • Execute non-interactive headless CI/CD runs (via agy and gemini) with read-only tool allowlists and structured JSON output, and synthesize spec-anchored *.evalset.json trajectories with human review.
  • Isolate untrusted code and autonomous execution using Agent Sandbox on GKE (gVisor / Kata microVMs and pre-warmed sandbox pools) and execute workflows to optimize execution runtimes (latency, token pruning, model tiering, and caching).
